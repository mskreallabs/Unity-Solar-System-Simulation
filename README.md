# 📌 About The Project

**Unity Solar System Simulation** is a simulation developed by **MSK Real Labs**.

The project was created to:

* Provide an interactive 3D view of the solar system
* Explore game development and 3D graphics in Unity
* Build a cross-platform simulation for WebGL and Windows

### 🎯 Project Type

```text
Type        : Simulation / Educational
Status      : In Development
Platform    : Windows / WebGL
Engine      : Unity
Language    : C#
Developer   : MSK Real Labs
Repository  : Public
```

## 🎮 Simulation Features

* Interactive environment
* Camera system for exploring planets

* Cross-platform support (Windows & WebGL)

# 📦 Installation

## 🪟 Windows — Prebuilt Version

### Step 1 — Download

Download the latest release:

**[Download Latest Release](https://github.com/mskreallabs/Unity-Solar-System-Simulation/releases/latest)**

### Step 2 — Extract

Extract the downloaded `.zip` file.

### Step 3 — Run

Open the extracted folder and run:

```text
Solar-System-Simulation.exe
```

## 🌐 WebGL Version

Simply open the hosted WebGL link in your browser to run the simulation directly without downloading.

# 🧰 Running From Source

## 🎮 Unity Project

### Requirements

Install:

* Unity Hub
* Git

### Unity Version

```text
Unity Editor: 6000.5.7f1
Platform: Windows / WebGL
```

### Setup

Clone the repository:

```bash
git clone https://github.com/mskreallabs/Unity-Solar-System-Simulation.git
```

Open **Unity Hub**.

Select `Add → Add project from disk` and choose the project folder.

---

# 🎮 Controls

## Keyboard & Mouse

| Key / Input    | Action        |
| -------------- | ------------- |
| `S`            | Capture screenshot in the Unity Editor |
| Left Click     | Select a target object                |
| Right Click    | Reset to the default target            |
| Automatic      | Rotate solar-system objects            |
